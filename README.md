## 🚀 How to Run Locally

### Option 1: Direct Browser Launch
Simply open the folder and double-click `index.html`. It runs immediately in Google Chrome, Microsoft Edge, Firefox, or any modern web browser without needing any build tools or runtime installations.

### Option 2: Local HTTP Server
If you want to run via a local web server:

**Using Python:**
```bash
python -m http.server 3000
```
Then visit `http://localhost:3000` in your browser.

## 🌐 Deploy to GitHub Pages

1. Push this repository to your GitHub account (`https://github.com/AdamuData2026/portfolio` or `https://github.com/AdamuData2026/AdamuData2026.github.io`).
2. In GitHub, go to **Settings** > **Pages**.
3. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
4. Your website will be live at `https://adamudata2026.github.io/portfolio/`!
